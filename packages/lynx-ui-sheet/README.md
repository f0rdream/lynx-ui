# Sheet

An extension of the Dialog.

## Installation

```bash
npm install @lynx-js/lynx-ui-sheet
```

## Basic Usage

```jsx
import { SheetRoot, SheetView, SheetBackdrop, SheetContent } from '@lynx-js/lynx-ui-sheet';

<SheetRoot>
  <SheetView>
    <SheetBackdrop />
    <SheetContent>
      <text>Hello World</text>
    </SheetContent>
  </SheetView>
</SheetRoot>
```

## Structure

```jsx
<SheetRoot>
  <SheetView>
    <SheetBackdrop />
```
